Diretrizes

Resumo da seção Visual do AGENTS.md, que é a fonte.

  • Tailwind v4 no className; CSS próprio só para os efeitos das cartas, máscaras e keyframes.
  • flex + gap para linhas e colunas; grid só para 2D de verdade. Espaço entre irmãos é gap, nunca margin.
  • Superfícies zinc, noir-glass e noir-glass-strong antes de criar outra. Cor reutilizada vira token em @theme.
  • Poucas bordas: separe com contraste, espaço e sombra.
  • Todo controle tem hover, focus-visible, active e disabled. Alvo de toque de 44 px no celular.
  • Movimento com propósito, menos de 300 ms, só transform/opacity, respeitando prefers-reduced-motion.
  • Funciona a 375 px sem scroll horizontal.
